# SKILL: daily_briefing

## Trigger
Called manually or by scheduled task

## Steps
1. Read Business_Goals.md for targets
2. Count completed tasks in /Done from past 24 hours
3. List all pending items in /Pending_Approval
4. List all active plans in /Plans
5. Check /Accounting/ for any flagged transactions
6. Write /Briefings/Briefing_[YYYY-MM-DD].md with:
   - Executive Summary (2-3 sentences)
   - Completed Today section
   - Pending Your Approval section
   - Upcoming section
   - One Proactive Suggestion
7. Update Dashboard.md Recent Activity

## Output
- Briefing file in /Briefings/
- Updated Dashboard.md
