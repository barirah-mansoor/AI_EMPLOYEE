# Gold Briefing Skill

**Mode:** AUTO-EXECUTE
**Trigger:** Daily schedule (9 AM) or manual
**Agent:** Orchestrator (combines all agents)

## Purpose
Generate comprehensive morning intelligence briefing combining email insights, task optimization, calendar analysis, and priority recommendations.

## Execution

```bash
bash run_ai_employee.sh gold_briefing
```

Or directly:

```bash
python3 Gold_Tier/Automation/orchestrator.py
```

## Capabilities

1. **Email Intelligence Summary**
   - New emails requiring attention
   - Urgent items flagged
   - Action items extracted
   - Response suggestions

2. **Task Optimization Overview**
   - Eisenhower Matrix summary
   - Top priority tasks
   - Schedule recommendations
   - Bottleneck alerts

3. **Calendar Analysis**
   - Today's meetings
   - Prep requirements
   - Attendee insights
   - Time allocation

4. **Priority Recommendations**
   - Do First items
   - Schedule today items
   - Deep work blocks
   - Protected time

## Output File

`Briefings/gold_briefing_YYYYMMDD.md`

## Briefing Format

```markdown
# Gold Tier Morning Briefing

**Generated:** YYYY-MM-DD HH:MM:SS

## 🔥 Immediate Actions
- [ ] Action 1 (URGENT)
- [ ] Action 2 (HIGH)

## 📧 Email Intelligence
### Urgent Emails
- From: sender@example.com
  Subject: [Subject]
  Action: [Required action]

### Pending Responses
- Email 1: Response drafted, awaiting review

## 📋 Task Overview
### Eisenhower Matrix Summary
| Quadrant | Count | Example |
|----------|-------|---------|
| Do First | 3 | Client deadline |
| Schedule | 5 | Strategy planning |
| Delegate | 2 | Admin tasks |
| Eliminate | 1 | Outdated item |

### Optimized Schedule
| Time | Activity | Type |
|------|----------|------|
| 09:00-10:30 | Deep Work | Focus |
| 10:30-11:00 | Email Processing | Admin |
| 11:00-12:00 | Meeting Prep | Prep |

## 📅 Calendar
### Today's Meetings
- 11:00 AM: Q1 Review (prep complete ✓)

## 💡 Recommendations
1. Complete urgent task by 10 AM
2. Block 2 PM - 4 PM for deep work
3. Delegate admin items to afternoon

## ⚠️ Bottleneck Alerts
- Waiting on: Client feedback
- Blocked: Project X pending resource

---
*Generated by Gold Tier AI Employee*
```

## Workflow Sequence

1. Run Email Agent → Process new emails
2. Run Task Optimizer → Analyze all tasks
3. Run Meeting Agent → Prep for today's meetings
4. Synthesize → Generate comprehensive briefing
5. Save → Write to Briefings folder

## Configuration

Settings in `Gold_Tier/Configs/workflows_config.yaml`:
```yaml
workflows:
  morning_briefing:
    enabled: true
    trigger: {type: "schedule", time: "09:00"}
    steps:
      - process_emails
      - analyze_calendar
      - optimize_tasks
      - generate_briefing
```

## Integration

- Email Agent: Provides email insights
- Task Optimizer: Provides task analysis
- Meeting Agent: Provides meeting prep
- Orchestrator: Coordinates and generates final briefing
