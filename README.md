# AI Employee Vault

A powerful **Personal AI Employee** system built on top of Claude Code. This vault operates as an autonomous assistant that manages tasks, files, communications, and reporting — all driven by a file-based workflow with human oversight.

---

## What Is This?

The **AI Employee Vault** is a self-contained operating system for an AI agent. It combines:

- **File-based task management** — Drop files into an Inbox and the AI triages them automatically
- **Automated monitoring** — A Python watchdog process watches for new inputs 24/7
- **Human-in-the-loop workflows** — Financial actions and sensitive operations require your approval
- **Complete audit trail** — Every action is logged in JSON with timestamps
- **Daily briefings** — You get a CEO-style summary each morning

Think of it as giving your AI employee a desk, an inbox, a calendar, and a notebook — all organized in a structured folder system.

## Key Features

### 1. Filesystem Watcher (24/7 Automation)

The `filesystem_watcher.py` script monitors the `/Inbox` folder in real-time using Python's `watchdog` library. When you drop a file:

1. It automatically copies the file to `/Needs_Action/`
2. Creates a companion metadata `.md` file with file details
3. Logs the action to today's JSON log
4. Updates the dashboard queue count

**Start the watcher:**
```bash
bash ~/AI_Employee_Vault/start.sh
```

### 2. Seven Core Skills

The AI Employee has seven invokable skills:

| Skill | Purpose |
|-------|---------|
| `process_inbox` | Triages items in `/Needs_Action/`, creates plans, routes approvals |
| `update_dashboard` | Refreshes `Dashboard.md` with live queue counts |
| `log_action` | Appends a structured entry to today's JSON log |
| `generate_plan` | Creates a Plan `.md` file for a specific task |
| `daily_briefing` | Generates a CEO-style daily summary |
| `vault_health` | Audits all folders and reports system status |
| `audit_week` | Summarizes the week's completed work |

Invoke any skill with: `claude -p "Run SKILL: skill_name"`

### 3. Priority System

All tasks are classified using a color-coded priority matrix:

| Priority | Icon | When to Use |
|----------|------|-------------|
| **URGENT** | :red_circle: RED | Payments, security alerts, client emergencies |
| **HIGH** | :yellow_circle: YELLOW | Client communications, deadlines within 48h |
| **NORMAL** | :green_circle: GREEN | General tasks, summaries, organization |
| **LOW** | :white_circle: WHITE | Archiving, social media scheduling |

### 4. Approval Workflow

The system enforces **human approval** for sensitive actions:

- **Financial actions** — Never auto-executed; always routed to `/Pending_Approval/`
- **External communications** — Must have a pre-approved file in `/Approved/`
- **Uncertain intent** — AI generates a plan and requests approval first

### 5. Complete Audit Trail

Every action produces a JSON log entry:

```json
{
  "timestamp": "2026-02-18T06:30:21.620307Z",
  "skill": "process_inbox",
  "action": "Processed test_task.txt and created plan",
  "files_affected": [
    "/home/sibling_admins/AI_Employee_Vault/Needs_Action/test_task.txt",
    "/home/sibling_admins/AI_Employee_Vault/Plans/PLAN_test_task_2026-02-18.md"
  ],
  "approval_required": false,
  "result": "success"
}
```

Logs are stored in `/Logs/YYYY-MM-DD.json` — one file per day.

### 6. Live Dashboard

`Dashboard.md` provides at-a-glance status:

```
| Folder         | Count | Purpose                           |
|----------------|-------|-----------------------------------|
| Needs_Action   | 0     | Items requiring processing        |
| Plans          | 1     | Task plans generated by AI       |
| Pending_Approval| 0    | Sensitive actions awaiting approval|
| Done           | 1     | Completed and archived tasks     |
...
```

The dashboard updates automatically when the watcher processes files or skills run.

### 7. Daily Briefings

Each morning, the `daily_briefing` skill generates a summary containing:

- Executive summary of the day's activity
- Completed tasks
- Items pending your approval
- Active plans and their status
- Proactive suggestions
- Upcoming deadlines

## Getting Started

### Prerequisites

- **Python 3.8+**
- **Claude Code CLI** installed (`npm install -g @anthropic/claude-code`)
- **watchdog** library (see `requirements.txt`)

### Installation

1. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Start the filesystem watcher:**
   ```bash
   bash ~/AI_Employee_Vault/start.sh
   ```

3. **Test the system:**
   ```bash
   # Drop a file into Inbox
   echo "Review my weekly schedule" > ~/AI_Employee_Vault/Inbox/test_task.txt

   # Run the inbox processor
   claude -p "Run SKILL: process_inbox"

   # Check the dashboard
   cat ~/AI_Employee_Vault/Dashboard.md
   ```

## How It Works

### The Workflow

```
+-----------+     +--------------+     +-------------+
|   Inbox   |---->| Needs_Action |---->|    Plans    |
|  (drop)   |     |  (auto-copied)    | (AI creates)|
+-----------+     +--------------+     +-------------+
                                           |
                                           v
                   +--------------+     +-------------+
                   |   Dashboard  |<----|   Approved  |
                   | (auto-updated)    |(human signs)|
                   +--------------+     +-------------+
                          ^
                          |
                   +--------------+
                   |     Done     |
                   | (archived)   |
                   +--------------+
```

### File Processing Pipeline

1. **File arrives** in `/Inbox/`
2. **Watcher detects** it -> copies to `/Needs_Action/` -> creates metadata `.md`
3. **AI runs** `process_inbox` skill -> reads file -> determines priority
4. **AI creates** a plan in `/Plans/` with recommended actions
5. **If approval needed** -> creates file in `/Pending_Approval/`
6. **You approve** -> move to `/Approved/` -> AI executes
7. **Task complete** -> move to `/Done/` -> update dashboard

## Non-Negotiable Rules

The AI follows these hardcoded rules:

1. **Log EVERY action** to `/Logs/YYYY-MM-DD.json` before executing
2. **Never take financial actions** — always create a `/Pending_Approval/` file
3. **Never delete files** — always move to `/Done/` when complete
4. **Always update Dashboard.md** after completing any task batch
5. **Never send external communications** without a human-approved file in `/Approved/`
6. **If uncertain about intent** — write a plan and request approval
